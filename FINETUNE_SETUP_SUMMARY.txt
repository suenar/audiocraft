QUICK START COMMANDS
================================================================================

OPTION 1: Automated (Easiest)
------------------------------
./scripts/finetune_encodec_quickstart.sh /path/to/your/music

OPTION 2: Step by Step
----------------------
# Step 1: Prepare dataset
python3 scripts/prepare_music_dataset.py \
    /path/to/music \
    egs/music_finetune \
    --split 0.9 \
    --recursive

# Step 2: Start training
dora run solver=compression/encodec_musicgen_32khz \
    dset=audio/music_finetune \
    continue_from=//pretrained/facebook/encodec_32khz \
    optim.lr=1e-4 \
    dataset.batch_size=32

OPTION 3: Using Training Grid
------------------------------
dora grid compression.encodec_finetune_music

RECOMMENDED WORKFLOW

1. READ DOCUMENTATION
   → Start with: README_ENCODEC_FINETUNE.md (5 min)
   → Quick ref: ENCODEC_FINETUNE_SUMMARY.md (5 min)

2. PREPARE DATASET
   → Organize music files in a directory
   → Run: python3 scripts/prepare_music_dataset.py --help
   → Review: Generated manifests in egs/music_finetune/

3. CONFIGURE (Optional)
   → Edit: config/dset/audio/music_finetune.yaml
   → Adjust sample rate, channels if needed

4. START TRAINING
   → Quick: ./scripts/finetune_encodec_quickstart.sh /path/to/music
   → Or: Use dora run commands from documentation

5. MONITOR PROGRESS
   → Watch: dora info -f <SIGNATURE> -t
   → Metrics: tensorboard --logdir /tmp/audiocraft_$USER/outputs/<SIG>

6. EVALUATE MODEL
   → Load: CompressionSolver.model_from_checkpoint('//sig/<SIG>')
   → Test: Run examples/encodec_finetune_example.py

7. USE MODEL
   → Standalone: For audio compression/reconstruction
   → With MusicGen: As custom tokenizer
